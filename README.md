## Introduction 

The main theme of the practical was modelling Evolutionary rescue. We were provided with a basic model
for simulating evolutionary rescue can be found ... Our task was to find our own research question we could ask 
and answer using the base model with our own additions. We decided to look at age structure adding 2 distinct age classes
to the model to see how these can effect the simulated evolutionary rescue probabilities.

## How to install 
required to run the program is R as well as R studio. We use the external packages ggplot2, tidy and diplr. 
if you do not have these packages installed the first code block in our markdown will let you install them. 

## File structure 
we have 4 folders in our repository. 
- AI usage: this folder contains all the AI prompts that were used in this project
- Data: this folder contains the raw data in the form of csv files
- Papers: this folder contains links to papers we used in our literature analysis
- plots: this folder contains the generated plots as png files.
